LOCAL APPLIANCE
1. Chế Độ Offline (Local Lab)
Thực hành trên máy chủ nội bộ. Dành cho admin hạ tầng, giảng viên biên soạn giáo trình và cấu hình node mạng độc lập không cần Internet.

  • 📁 Lưu trữ: Hệ thống tệp /opt/unetlab/labs/
  • ⚡ Hiệu năng: Trực tiếp qua Kernel KVM & Docker nội bộ
  • 🚫 Không yêu cầu kết nối mạng ra Internet
Thông tin tài khoản: Local User: admin / pnet (Session ID DB)
☁️
MULTI-TENANT HUB
2. Chế Độ Online (Git Repo Hub)
Môi trường đám mây phân tán kiểu GitHub. Dành cho học viên tham gia lớp học, trao đổi bài lab, clone/fork và thi đấu Cyber Range.
  • 👤 Xác thực: Tài khoản Cộng đồng (Online Profile / Token)
  • 🍴 Mini-Git: Snapshot versioning, Fork bài lab đồng nghiệp
  • 🛡️ Cgroups v2: Giới hạn RAM/CPU theo từng Tenant ID
  • 📦 Tự động đồng bộ Catalog qua GitHub CDN công khai
Thông tin tài khoản: Online Hub Token (Multi-tenant Pod ID)
